# Обновление v3

Загрузите содержимое этой папки в корень репозитория GitHub и подтвердите замену файлов.

Что добавлено:
- закреплённый 3D-просмотр на телефоне;
- готовые крупные превью без загрузки всех MDL при старте;
- избранное;
- сравнение образов A/B;
- ракурсы спереди, сбоку, сзади и 3/4;
- снимок образа PNG и системная отправка;
- движения персонажей: ожидание, ходьба, бег, приседание, прыжки, плавание, действия с оружием и реакции;
- прыжок, длинный прыжок, стрельба/удар и перезарядка автоматически повторяются с интервалом 3,5 секунды; длинная анимация сначала завершается полностью;
- падения останавливаются на последнем кадре; кнопка ↺ запускает любое движение заново;
- прицеливание, стрельба и перезарядка подбираются под выбранное оружие; недоступные действия отключаются;
- выбор движения сохраняется на устройстве; подписи доступны на русском и английском;
- скорость и пауза;
- шапки движутся вместе с костями модели.

Миниатюры шапок находятся в `assets/previews-v2/`, а миниатюры моделей — в `assets/player-previews-v1/` и `assets/player-previews-v2/`. При публикации сохраняйте эти пути и файлы WebP.

Анимации для 174 моделей восстановлены в `assets/player-motion-v1/` с сохранением облегчённой геометрии и текстур. Для «Крыса · Half-Life» оставлены только действия из её исходного файла. При загрузке выбирается один файл текущей модели; весь каталог моделей заранее не скачивается.

Для повторной подготовки анимаций используется `scripts/expand-motions.mjs --sources <manifest.json> --root <папка исходников>`. Формат исходного списка: `{id, source, currentFile, uniformScale?}`; путь `currentFile` задаётся относительно `assets/`. Исходные серверные MDL не заменяются.
